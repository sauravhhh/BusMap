# GuwahatiBusMap

Interactive map of Guwahati's ASTC city bus routes on OpenStreetMap.

- **Live:** https://sauravhhh.github.io/GuwahatiBusMap/
- 37 city bus routes (RTA Kamrup (M) Mini City Bus list, 2019) with full stop sequences
- Toggle routes, search by route number or place, tap any stop to see which routes serve it

Sources: RTA Kamrup (M) route list (2019) and the ASTC “Uberization” SCR city service list
(astc.assam.gov.in). Schematic map — lines join stops in order, not GPS traces; a few minor
stops are placed approximately. Map data © OpenStreetMap contributors.
